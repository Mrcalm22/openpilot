# Turbopilot v0.1 Release

## Scope

Turbopilot v0.1 is the first local-first public OTA build for `tizi` hardware.

Included:

- Public app-layer OTA through `release-tizi` and `staging-tizi`.
- Turbopilot offroad home screen and core settings branding.
- Comma registration offroad alert suppression.
- Local Turbopilot device identity at `/data/turbopilot/identity.json`.
- Device settings display for Turbopilot Device ID.
- Release notes shown through the normal updater UI.

Excluded:

- AGNOS boot logo and low-level system image branding.
- Turbopilot cloud storage.
- Turbopilot account binding or mobile app.
- SunnyLink-like remote control service.
- Full sunnypilot feature parity.
- Vehicle-specific production validation.

## Baseline

- Base software: openpilot `0.11.1`
- Hardware target: comma `tizi`
- AGNOS target: `18.4`
- Release branch: `release-tizi`
- Staging branch: `staging-tizi`

## Minimum Acceptance

- Device boots to Turbopilot UI.
- Software page shows `Turbopilot 0.1.0`.
- Device page shows a `tp-xxxx-xxxx-xxxx-xxxx` device ID.
- No comma registration alert is shown offroad.
- Updater can fetch the public Turbopilot repository.
- OTA candidate can be staged and applied after reboot.
- Panda jungle ignition starts the normal onroad process set.

## Known Gaps

- GitHub HTTPS may be slow or blocked on some China networks; GitHub SSH worked on the first test device.
- Remaining comma references exist in translations, legal text, installer/recovery flows, and disabled or hidden cloud-related surfaces.
- True vehicle validation is still required before customer delivery.
